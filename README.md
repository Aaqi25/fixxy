# FIXXY — AI-Powered Personalized Tutor for AI/ML

> **FIXXY** is an adaptive AI tutor that doesn't just tell students the correct answer — it identifies *why* they made a mistake and provides a personalized teaching intervention to help them understand the concept.

## 🚀 Overview

Learning AI/ML concepts is often difficult because students can arrive at the same wrong answer for completely different reasons.

Traditional learning systems usually follow:

```text
Question → Wrong Answer → Correct Answer

Question
   ↓
Student Answer
   ↓
Correct / Incorrect Detection
   ↓
Misconception Diagnosis
   ↓
Teaching Strategy Selection
   ↓
Knowledge Retrieval (RAG)
   ↓
Personalized AI Explanation
   ↓
Hint + Retry
   ↓
Transfer Question
   ↓
Mastery Update
